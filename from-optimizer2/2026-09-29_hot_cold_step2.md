# Вариант 3, шаги 1–2: горячие и холодные таблицы в GPU-узле — сделано, замерено на 3050

Ветка `opt2/hotcold` (от `opt2/main` 9cd3e7e; после слияния перебазируюсь на master). Тип (а): те же double, digest
прогона = digest одиночного тренера.

**Что сделано:**
- **Шаг 1 (ee1ea6e).** Убран массив строка → решение (0.79 ГБ VRAM при 200 корзинах). Номер решения едет в обновлении.
  Стоимость ~2 % скорости [замер]: 353 042 → 346 201 ит/с на проходе 16384.
- **Шаг 2 (bb7e838, 7e2b585).** Ветка целиком горячая (VRAM) или холодная (закреплённая память хоста). Верх всегда
  горячий.
- **Проверка памяти до старта.** VRAM (горячее + игра + резерв под буферы пачки) сравнивается со свободной, закреплённое
  + резерв — с доступной RAM. Если не хватает — отказ с числами, а не OOM.
- **Файлы узла от размещения не зависят.** Тест: файл с размещением A побайтно равен файлу CPU-узла, грузится с
  размещением B, обучение продолжается бит в бит.
- **Ключи узла:** `gpu_cold` (список веток), `vram_reserve`, `host_reserve`.

**Тесты на ноуте 3050** [замер]: `test_distcfr` + `test_dist_procs` — 63 passed, из них 12 новых:
- холодных веток нет / все / через одну / случайные, шагами и конвейером;
- 3 игрока, у каждого узла своё размещение;
- новое размещение между пачками;
- файл A → B;
- отказы проверки памяти;
- по TCP: GPU-узел с холодными ветками + GPU + CPU.

**Штраф PCIe** [замер: 3050, pot16 от 100M, 1M итераций, проход 4096; digest везде IDENTICAL 063e8f923e381234]:

| холодная доля работы | холодным всё, включая σ (A) | σ в VRAM (B, оставлен) |
|---|---|---|
| 0.013 % | −1.8 % | шум |
| 0.079 % | −3.6 % | 0.0 % |
| 0.22 % | −5.8 % | шум |
| 0.75 % | −10.1 % | −2.0 % |
| 5.1 % | −19.6 % | −8.3 % |
| все ветки | −65 % | −33 % |

**Почему B.**
- В A платил прямой проход: противник на холодном решении читает σ по шине (~1 мкс), и вся плитка блока ждёт на
  барьере. Это остановка на каждый холодный элемент, а не плата за байты.
- В B σ всех строк остаётся в VRAM. Проходы от размещения не зависят, по шине ходит только сложение (regret, ssum,
  visits холодных строк).
- Цена B: холодная ячейка освобождает 16 Б VRAM вместо 24.

**200 корзин на одной 5070** (модель B) [расчёт по замеренной работе веток]:
- таблицы 464.9M ячеек, 196.9M строк;
- при 10–10.5 ГБ VRAM под таблицы холодными становятся 1.6–2.1 ГБ: 353–371 ветка, **0.08–0.14 % работы**;
- по замеру на 3050 при такой доле штрафа нет.
