# Вариант 3 целиком, 5070 замерена, выгрузка блюпринта из файлов узла — 29.09, вечер

Ветка `opt2/hotcold` (от master 86eddfd). Тип (а) везде: digest прогона = digest одиночного тренера, блюпринт — байт в
байт. Числа — в `opt2/results/` ветки.

## Что сделано

1. **Шаг 3 — узел без полных копий таблиц на хосте.**
   - Сохранение, загрузка, digest и экспорт идут кусками. Байты файла узла прежние.
   - Битый файл отклоняется: по размеру — до таблиц, по контрольной сумме — после; во втором случае узел не работает
     до удачной загрузки.
   - [замер] Сохранение и загрузка +0.14 ГБ при любом размере таблиц.
2. **Шаг 4 — план горячего и холодного.**
   - GPU считает обновлённые строки по веткам; счётчики скорость не меняют [замер].
   - `dist_train --vram-budget --work --replan`: новое размещение из файла чекпоинта.
3. **Чекпоинты по ходу:** `dist_train --save-every N --keep-previous`, паспорта. Паспорт, не совпадающий с файлом,
   отклоняется. `dist_merge` сверяет сид и Linear.
4. **Один узел по TCP** не гоняет значения и дайджесты [замер, 3050]: 318k → 339k ит/с.
5. **Commit под WDDM** [замер: ноут и ПК]: память устройства списывается в commit процесса. Проверка памяти до старта
   сравнивает и commit. Все запуски на ПК идут с проверкой commit перед каждым шагом (запас 8 ГБ) и с сэмплером
   commit.
6. **Выгрузка блюпринта из файлов узла** (решение пользователя):
   - `scripts/dist_export_blueprint.py` без таблиц Trainer и FlatTrainer;
   - [замер] на pot16 100M результат байт в байт равен боевому `blueprint_hunl3w100_pot16_s0.bin`: MD5 7634D5BF…,
     1.05 ГБ, 82 с.

## Для плана «200 корзин на одной 5070» [оценка]

- **Скорость:** ~1.0M ит/с при 0.08–0.14 % холодной работы. Замер pot16 — 1.07M по TCP; размер таблиц на скорость
  почти не влияет.
- **Память:** узлу нужно ~16 ГБ commit. В обычном состоянии ПК свободно ~5 ГБ; решение об освобождении — у
  пользователя.
- **Блюпринт:**
  - ~12.9 ГБ;
  - выгрузка ~15–25 мин;
  - ~17 ГБ записи последовательно, пик памяти ~3.5 ГБ;
  - загрузка такого блюпринта игроком (~9 ГБ в памяти) — вопрос основной.
