# Покерный стол NegativePluribus

Игра хедз-ап против обученного blueprint'а в браузере. Зависимостей ставить не надо: чистый Python поверх
движка, абстракции и blueprint'ов проекта. Нужно собранное ядро (`python scripts/build_fast.py`).
Сервер слушает только `127.0.0.1`, с других машин к нему не подключиться.

## Запуск и остановка

Двойной клик по `webapp\start.bat`: поднимется сервер, скрипт дождётся, пока он начнёт отвечать, и откроет браузер
(`http://127.0.0.1:8777`). Если сервер уже запущен, второй не поднимается, просто открывается страница. Если сервер
не поднялся за 40 с, окно покажет конец `webapp\server_err.log`. Файлы `.bat` намеренно только латиницей: cmd.exe
путает строки в батниках с русским текстом после `chcp 65001`.
Вручную из корня проекта:

```powershell
python webapp\server.py
```

Другой порт: переменная `NP_WEB_PORT`. Первый запуск грузит бота несколько секунд (файл около 936 МБ); если
страница открылась раньше, обнови её (F5). Остановка: `webapp\stop.bat` (останавливает только процесс сервера по `webapp\server.pid`, который пишет сам сервер), закрыть его свёрнутое окно или Ctrl+C.
Логи: `webapp\server_out.log`, `webapp\server_err.log`.

## Управление за столом

- Фолд, чек-колл, рейз — кнопками. Размер ставки: пресеты (префлоп в bb, постфлоп в % банка, последний — олл-ин),
  слайдер (слева мелкие размеры крупнее) или точная сумма в поле; потом одна кнопка «Рейз до N» / «Бет N» /
  «Олл-ин». Любой размер допустим: бот переводит его в свою сетку по статье.
- Клавиатура (любая раскладка): `F` фолд, `C` чек/колл, `1..n` пресеты, `A` выбрать олл-ин (только выбрать),
  `↑`/`↓` размер ±1bb, `Enter` поставить, `N` новая раздача / сесть заново. Пока вводишь сумму, клавиши стола молчат.
- Раздача проигрывается по шагам: бот «думает», ставит, фишки уходят в банк, выкладывается улица. Пока ход бота,
  панель действий серая.
- Стеки по умолчанию переходят из раздачи в раздачу, пока у кого-то не кончатся фишки; тогда «Сесть заново».
  Галочка «играть до банкротства» в блоке «Сессия» возвращает равные стеки каждую раздачу. Глубину стека бот не
  различает (её нет в ключе infoset'а): при других стеках он играет стратегию своей глубины обучения.
- Комбинации пишутся по-русски; на вскрытии подсвечиваются лучшие пять карт победителя.
- Разбор после раздачи: для каждого хода бота — его вероятности в этой точке, для ваших — что сыграл бы blueprint
  на вашем месте. Во время раздачи вероятности скрыты: они выдали бы руку бота. Разбор есть и у рук в истории.
- «Сессия»: график результата, bb/100 с 95% доверительным интервалом, экспорт истории рук в формате PokerStars
  (для трекера, время в UTC), сброс сессии. «Настройки»: авто-раздача, карты бота после фолда, bb/фишки, темп бота.

## Какие боты есть и как добавить своего

Список ботов — не в коде, а в настройках:

- `webapp/bots.json` (в git) — blueprint'ы проекта. Пути от корня проекта: `data/blueprint_*.bin` и т. д.
  Поле `default` — бот по умолчанию. Папка `data/` может быть ссылкой на другой диск: пути не меняются.
- `webapp/bots.local.json` (не в git) — боты этой машины: абсолютные пути (другая папка, флешка) или пути от
  корня проекта. Запись с тем же `id` заменяет общую. Шаблон — `webapp/bots.local.example.json`.
- Большие файлы своих ботов можно класть в `webapp/blueprints/` (не в git).

У каждого бота:

- `blueprint` — файл `blueprint_*.bin`;
- `bucketer` — его корзины `buckets_*.json`, обязательно;
- `tables_dir` — папка с таблицами корзин `*.npbt`, по умолчанию `data/bucket_tables`. Без таблицы бот тоже
  работает, решения чуть медленнее;
- параметры игры, на которой он учился: `stack_bb`, `preflop`, `postflop` (доли банка), `max_raises`.
  **Они должны совпадать с обучением**, иначе бот играет не в свою игру.

Бот, у которого не найдены файлы, показывается в списке неактивным с пометкой «нет файлов» — сервер от этого
не падает. После правки настроек перезапусти сервер (`stop.bat` → `start.bat`).

## Перенос на другой ПК

Скопировать проект (или `webapp\` + пакет `negpluribus\` + `scripts\build_fast.py` с `csrc\`), один раз собрать
ядро, blueprint'ы и корзины положить в `data\` или описать в `bots.local.json`.

## Устройство

- `server.py` — сервер и API: `/api/bots`, `/api/state`, `/api/select`, `/api/new`, `/api/action`, `/api/reset`,
  `/api/rebuy`, `/api/settings`, `/api/export`.
  Раздачу ведёт движок проекта (`HandState`), бот — `BlueprintAgent` на том же blueprint'е и тех же корзинах, что
  в дуэлях; корзины через C++ и таблицу (`CoreBuckets`, при загрузке сверяются с Python-бакетером).
- `static\` — интерфейс, HTML/CSS/JS без сборки.
