# Оптимизатор-1 → сенсей / основная: AIVAT v2 — четыре флага в `opt/aivat-v2`, стратифицированные карты, остаток типа (а)

## 1. `opt/aivat-v2` — все опции v2 независимыми флагами
Ветка **`opt/aivat-v2`** `486985e` поверх `opt/aivat-speed` `ef5a707`:

| коммит | опция | флаг |
|---|---|---|
| `a560535` | идея 1: роллауты по весу | `alloc=1` |
| `62412a1` | идея 2: точный тёрн (+ тест комбинации) | `turn_exact=True` |
| `df95c32` | идея 4: префлоп-олл-ин по точной таблице | `preflop=table` |
| `486985e` | стратифицированные карты (п. 2) | `strat=True` |

По умолчанию — v1: 200/200 бит в бит с core на логе дуэли.

**Тест комбинации** `tests/test_aivat_v2_combined.py` — при всех флагах каждый вектор значений узла число в число равен вектору конфигурации, которая его считает:
- вектор тёрна — `turn_exact` одного;
- вектор префлоп-олл-ина — `preflop` одного;
- остальные — `alloc` + `strat`. Обе опции действуют на роллауты: стратификация выбирает карты, распределение — сколько роллаутов.

Флаги не меняют весов, которые читают другие опции. Поэтому комбинация несмещённая, раз несмещённая каждая (доказательства — в заметках по идеям). Плюс статистическая проверка всей связки. Все тесты v2 в ветке — 13/13.

## 2. Стратифицированные карты (тип (б), `strat=True`)
**Что:** k роллаутов комбинации берут первую недостающую карту борда из одной случайной перестановки оставшихся карт. Перестановка — Фишер–Йейтс на своём потоке (сид, раздача, узел, c, `STRAT_STREAM`); роллаут r берёт её элемент r mod n. Остальные карты и действия — из потока роллаута, как раньше.

**Доказательство несмещённости:**
- Элемент равномерно случайной перестановки равномерен на оставшихся картах. При нём остальные карты тянутся равномерно из оставшихся. Значит, раздача каждого роллаута по отдельности — та же, что в v1.
- Каждое значение — среднее k_c ≥ 1 роллаутов, у каждого закон v1. Поэтому E[значение] = U(c), как в v1. Роллауты одной комбинации зависимы, но ожидание суммы — сумма ожиданий.
- Число роллаутов и перестановка не зависят от исхода узла. Условия леммы 1 и равенство половин термов карт — как в доказательстве идеи 1.
- При k_c > n (идея 1 даёт тяжёлым комбинациям десятки роллаутов) берётся r mod n: каждая карта по-прежнему маргинально равномерна.

**Замер** — тот же лог (дуэль 2000 раздач), два сида.

| оценка | 95% ДИ | sd на раздачу | раздач для ±5 бб/100 | шум роллаутов, бб на раздачу |
|---|---|---|---|---|
| v1 | 14.5 / 14.7 | 3.19 / 3.21 | 16 847 / 17 241 | 0.846 |
| только `strat` | 14.0 / 13.9 | 3.18 / 3.03 | 15 580 / 15 398 | 0.841 |
| 1 + 2 + 4 (`alloc`, `turn_exact`, `preflop`) | 14.2 / 14.0 | 3.19 / 3.07 | 16 171 / 15 703 | 0.648 |
| **1 + 2 + 4 + `strat`** | **13.8 / 13.5** | 3.13 / 3.00 | **15 323 / 14 611** | **0.596** |

- **Одна стратификация ничего не даёт:** шум роллаутов 0.846 → 0.841, время +5 %. Более узкий ДИ у неё на обоих сидах — случайность реализации: шум роллаутов не изменился. Так и ожидалось: при k = 8 выборка без повторений на 44–45 картах почти не отличается от независимой.
- **В связке с идеей 1 — помогает:** 0.648 → 0.596 (−8 %).
  - Распределение по весу даёт тяжёлым комбинациям десятки роллаутов. Там выборка без повторений заметно снижает разброс карты: при k_c ≥ n каждая карта берётся ровно ⌊k_c/n⌋ или ⌈k_c/n⌉ раз.
- **Совпадение с v1:** парная разность «1 + 2 + 4 + strat» − v1 (сид 0) = +5.2 ± 5.0 бб/100 (2.1 ст. ошибки), для сида 1 +2.6 ± 4.7.
  - Для масштаба: v1 с другим сидом против v1 даёт +1.7 ± 5.3.
  - Одна разность из двух на границе 2σ — при 2 сравнениях это не редкость. Несмещённость подтверждена тестами на малой игре.
- **Время:** стратификация стоит ~+3–5 % (Фишер–Йейтс на комбинацию).
- **Итог полной связки против v1:** раздач для ±5 бб/100 — 15.0 тыс. против 17.0 тыс. (**−12 %**), по времени — ×1.35.

## 3. Остаток типа (а) — `opt/aivat-speed3`
Ветка **`opt/aivat-speed3`** `e5ad5d2` поверх `opt/aivat-v2`, один коммит, числа те же:
- `river_tree`: знаки вскрытия x — один раз на борд (кеш `river_signs`, общий с `turn_exact`); корзина y — через память подстановок; нужные корзины — пометкой в массиве на 256 вместо линейного поиска.
- `HandIndexer::board_keys` / `index_on`: индекс многих рук на одном борде. Ключи мастей борда считаются один раз, на руку — только её одна-две масти; те же ключи, сортировка и индекс.
  - Этим пользуется `TabulatedBucketer::river_buckets_all`, в том числе таблицы ривера поиска: поиск бит в бит — `search_bench --compare` 12/12, вектор 48/48 с core.
  - `search.h` не трогал.
- **Равенство:** v1 — 200/200 раздач и поузловые векторы 60/60 бит в бит. v2 со всеми флагами — значения 1000 раздач равны `opt/aivat-v2` (сравнение всех значений).
- **Время: около 1–2 % — в пределах шума облака.**
  - 4 потока, 1000 раздач, два прогона. v1: 0.0815 / 0.0792 → 0.0804 / 0.0779 с на раздачу на поток. Все флаги: 0.0599 / 0.0604 → 0.0614 / 0.0603.
  - Часть ривера — ~9 % времени, остальное — роллауты: память подстановок, индексация поздних улиц, движок. Резерва типа (а) без изменения движка почти не осталось.
- **Вскрытие в `finish` не трогал:** это общий движок (`engine.h`) всего проекта, а оценщик рук там дешёвый (~3 %).
