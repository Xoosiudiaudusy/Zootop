# Оптимизатор-1 → сенсей / основная: H2 — играемая средняя векторного CFR = средняя таблицы

Ветка **`opt/vector-average`** (коммит `d1b420b`), пока от `opt/river-exact` (`0b8be7f`): нового core на GitHub ещё нет, `refs/zootop` тоже нет.
Правка — несколько строк в `solve()` и `vector_loop()` в `search.h`, область `prepare_vector` (1bcfdb8) не задета.
Перенесу на новый core сразу после пуша; если нужно раньше — вишней на bfce378, конфликтов не жду.

## Причина (две, не одна)
Играемая `r["average"]` в векторном режиме — это `ctx.ours`: раз в итерацию прибавлялась текущая стратегия класса нашей руки.
Она отличалась от строки таблицы (`average_table`, её меряет `subgame_exploitability`) по двум причинам:
1. **Веса:** `ours` всегда брал вес t, а таблица под DCFR берёт t² (под CFR+ и Linear — t).
2. **Сдвиг на итерацию:** `ours` читал регреты **после** обновления итерации t, то есть σ(t+1), а таблица складывает σ(t), с которой итерация шла.
   Это и есть остаток у Linear и CFR+.

Замер [облако, 1 поток; тёрн 40 итераций, ривер 200; HU 200bb pot16], max |играемая − табличная| по действию:

| корень | было: Linear / CFR+ / DCFR | только сдвиг исправлен | исправление |
|---|---|---|---|
| тёрн, первым | 0.0067 / 0.0093 / 0.0325 | 0.0010 / 0.0004 / 0.045 | **0 / 0 / 0** |
| тёрн, против ставки | 0.0109 / 0.0067 / 0.0229 | 0.0009 / 0.0006 / 0.031 | **0 / 0 / 0** |
| ривер, первым | 0.0039 / 0.0005 / 0.0231 | 2e-5 / 9e-6 / 0.024 | **0 / 0 / 0** |
| ривер, против ставки | 0.0043 / 0.0006 / 0.0184 | 3e-5 / 2e-5 / 0.020 | **0 / 0 / 0** |

- Малый остаток после исправления сдвига (тёрн ~1e-3) — ещё одно отличие: строка таблицы — сумма по всем рукам класса с весом их досягаемости (и ×48/44 на тёрне), а `ours` — одна текущая стратегия класса.
- Это не одно и то же число, поэтому по требованию ТЗ `ours` в векторном режиме убран.

## Исправление
В векторном режиме `r["average"] = r["average_table"]`: строка класса нашей руки с весами самого решателя (t или t² под DCFR).
Накопление `ours` в `vector_loop` удалено. В MCCFR (без вектора) всё как было.

## Ворота [замер]
- **Без флага (MCCFR):** `search_bench --threads 1 --scale 0.05 --compare`, 12 корней флоп/тёрн/ривер: **12/12 идентичны** `opt/river-exact`.
- **С вектором** (тёрн и ривер × Linear / DCFR / CFR+ / k200 DCFR / exact / warm, 48 решений, 1 поток):
  - `final` и `likelihood()` обоих мест — **48/48 идентичны**;
  - `average` — **изменилась во всех 48**: так и задумано, теперь она равна таблице.
  - «Бит в бит с `--search-vector linear`» в буквальном смысле невозможен: ТЗ требует убрать остаток Linear, а это меняет играемую среднюю. Всё остальное — бит в бит.
- **Тест** `test_played_average_is_the_table_average`: тёрн, ривер, ривер против ставки × Linear / CFR+ / DCFR × 1 и 4 потока, точное равенство. `test_vector_cfr.py`: 18 passed. Тесты поиска (`test_vector_cfr`, `test_search_core`, `test_search_tree`, `test_core_search_agent`, `test_search`, `test_search_models`): **61 passed**.
