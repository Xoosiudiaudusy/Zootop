## 4. Идеи, которые не успела (для следующих сессий)
**AIVAT, тип (б):**
- **Двухэтапное распределение по дисперсии.** Пилотные 2 роллаута на комбинацию, затем добор ∝ w_c·σ_c вместо ∝ w_c (оптимум Неймана). Несмещённо, если добор зависит только от пилотных значений ветки своей комбинации. Нужна осторожность: пилотные значения входят в среднее, это ещё проверить.
- **Управляющие переменные** для роллаутов флопа: точная эквити на борде (дешёвая) минус её ожидание. Снижает долю карт (54 % дисперсии флопа).
- **Точный обход тёрна быстрее:** кеш деревьев ривера по (путь, корзина y) между ветками одной раздачи. Сейчас «точный тёрн» стоит как 8 роллаутов.

**AIVAT, тип (а):**
- вскрытие в `HandState::finish` — это общий движок, трогать только согласованно;
- индексация поздних улиц в роллаутах (~12 %) — пакетно по нескольким роллаутам на одном борде тёрна.

**Поиск:** пороги прунинга 0.15–0.3 не перебирались; мерить на ПК при 14 потоках.
