# Оптимизатор-1 → сенсей / основная: AIVAT v2 = идеи 1 + 2 в одной ветке (`opt/aivat-v2`)

Ветка **`opt/aivat-v2`** `62412a1` поверх `opt/aivat-speed` `ef5a707`, два коммита:
- `a560535` — идея 1, «роллауты по весу» (`alloc=1`), тот же коммит, что в `opt/aivat-v2-alloc`;
- `62412a1` — идея 2, «точный тёрн» (`turn_exact=True`), перенесена из `opt/aivat-v2-turn` `9abdadf`, плюс тест комбинации.

Флаги независимы, по умолчанию — v1 (200/200 бит в бит с core на логе дуэли). `FastAivat(..., alloc=1, turn_exact=True)` / `AivatEvaluator(..., alloc, turn_exact)`.

## Почему комбинация несмещённая
Опции действуют на разные ветви:
- `turn_exact` — на состояния тёрна с известной картой;
- `alloc` — только на ветви, которые остаются роллаутами.

Ни одна не меняет веса, которые читает другая: веса — это досягаемость и σ x, не значения.
- Поэтому при обоих флагах **каждый вектор значений узла число в число равен вектору той опции, которая его считает**. Тест `test_each_vector_is_the_one_of_its_option` проверяет это на 180 раздачах малой игры.
- Каждый терм — тот же, что у одной из опций, а несмещённость каждой доказана в её заметке: 2026-09-29_aivat-v2-alloc.md, 2026-09-29_aivat-v2-turn.md. Значит, комбинация несмещённая.
- Отдельно проверено статистически: самоигра, случайный игрок, среднее каждого вида терма 0.

## Замер: тот же лог (дуэль 2000 раздач, `base_s0` против `ctrl_s1`)
Два сида, 3 потока. ДИ и sd детерминированы; время ниже — отдельно, на свободной машине.

| оценка | бб/100 | 95% ДИ | sd на раздачу | раздач для ±5 бб/100 | роллаутов на раздачу |
|---|---|---|---|---|---|
| v1, сид 0 | +3.5 | 14.5 | 3.19 | 16 847 | 78 593 |
| v1, сид 1 | +5.2 | 14.7 | 3.21 | 17 241 | 78 593 |
| **v2 (1 + 2), сид 0** | +4.6 | **14.2** | 3.19 | **16 167** | **30 950** |
| **v2 (1 + 2), сид 1** | +6.4 | **14.0** | 3.07 | **15 701** | **30 950** |

- **Совпадение.** Парная разность v2 − v1 (сид 0) = **+1.15 ± 3.10 бб/100** — ноль в пределах шума.
- **Шум роллаутов** (два сида): v1 0.846 бб на раздачу → **v2 0.648 (−23 %)**.
- **ДИ уже** на обоих сидах. **Раздач для ±5 бб/100: ~15.9 тыс. против ~17.0 тыс. (−6.5 %).**
- **Время** (свободная машина, 4 потока, первые 1000 раздач, два прогона):
  - v1 — 0.083 / 0.081 с на раздачу на поток (стена 20.7 / 20.3 с);
  - **v2 — 0.060 / 0.061 (стена 15.0 / 15.4 с) — ×1.35**;
  - к core (0.163) вместе с кругом 1 — **×2.7**.
- **Для сравнения:**
  - одна идея 1 — ×1.55 по времени при том же ДИ;
  - одна идея 2 — то же время и ДИ уже;
  - вместе — середина по времени и лучшее по ДИ. Какую комбинацию брать умолчанием — решение пользователя и основной.
